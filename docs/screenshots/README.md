## Sebelum publikasi

- Gunakan akun/profil sintetis, bukan nama, NIK, tanggal lahir, alamat, telepon atau email pribadi.
- Jangan tampilkan foto biometrik, embedding, bukti GPS, atau lampiran nyata tanpa izin publikasi yang sesuai.
- Pastikan address bar, browser tools, notifikasi, log, API key, kode pairing, token undangan dan cookie tidak tertangkap.
- Untuk enrollment/kiosk, kamera dapat dihentikan pada screenshot struktur UI. Visual itu tidak membuktikan keberhasilan identifikasi.
- Ambil ukuran konsisten, misalnya viewport desktop 1440×900, dengan zoom browser yang sama. Tambahkan caption yang menjelaskan role dan konteks.
- Tinjau kembali file hasil capture sebelum menambahkannya ke Git.

Setelah file asli yang aman tersedia, tambahkan Markdown relatif di README utama, misalnya `![Dashboard HR](docs/screenshots/01-dashboard.png)`. Jangan menambahkan link tersebut sebelum filenya ada.
